# 🤖 AI Sotuvchi — Autonomous AI Sales Agent & Smart Mini-CRM Platform

> **"Biz sizga ko‘proq lead topib bermaymiz. Mavjud leadlaringizdan ko‘proq sotuv qilishingizga yordam beramiz."**

![AI Sotuvchi](https://images.unsplash.com/photo-1556742049-0a67e557b63b?w=1200&auto=format&fit=crop&q=80)

**AI Sotuvchi** — O'zbekiston va xalqaro bozorlardagi online va offline bizneslar (Telegram, Instagram, WhatsApp orqali savdo qiluvchilar) uchun yaratilgan **Avtonom AI Savdo Agenti + Intellektual Mini-CRM + Lead Scoring + ChatGPT 4o Voice Cloning** SaaS platformasidir.

---

## 🌟 Asosiy Xususiyatlar (Key Features)

### 1. 🤖 AI Sotuvchi & Universal Maslahatchi (ChatGPT 4o & Gemini)
- O'zbek tilida (lotin, kirill, aralash so'zlar) va shevalarda tabiiy muloqot.
- Har qanday umumiy savollarga (texnologiya, solishtirish, maslahat, erkin suhbat) chuqur va intellektual javoblar.
- Do'kon mahsulotlari, narxlari, aksiyalari va muddatli to'lovlari bo'yicha qat'iy va ishonchli sotuv olib borish.

### 2. 🎙 Ikki Tomonlama Ovozli Muloqot & Voice Cloning
- **Speech-to-Text**: Mikrofonga gapiring — ovozingiz real vaqtda matnga aylanadi.
- **O'zbek shevalari tahlili**: Toshkent, Samarqand, Vodiy og'zaki nutq so'zlarini (*"ob ketaman", "tushib berin", "karta raqam bering"*) 100% tushunish.
- **ChatGPT 4o Studio Audio**: Nova, Onyx, Alloy, Shimmer insoniy ovozlari.
- **🧬 Instant Voice Cloning**: Gapiruvchining o'z ovozini 3 soniyada o'rganib olib, uning ovozida gapirish!
- **📞 Qo'ng'iroq Rejimi (Continuous Voice Call)**: Xuddi telefon orqali gaplashayotgandek hands-free ovozli suhbat.

### 3. 🎯 Real-time Lead Scoring & Mini-CRM Kanban
- **Mijoz holatini avtomatik aniqlash**:
  - 🔥 **Hot Lead (Score 80-100)**: "Karta raqam bering, olaman" deganda darhol sotuvchiga yo'naltirish.
  - 🟡 **Warm Lead (Score 50-79)**: Narx va bo'lib to'lash shartlari bilan qiziqqanlar.
  - 🔵 **Cold Lead (Score 0-49)**: Dastlabki bosqichdagi mijozlar.
- **Vizual Kanban Pipeline**: `Yangi` → `Aloqada (AI)` → `Qiziqmoqda (Warm)` → `🔥 Hot Lead` → `🎉 Yutildi (Sotildi)` → `Yo'qotildi`.
- Har bir mijoz uchun to'liq profil, suhbat tarixi (transcript) va ichki eslatmalar.

### 4. 📚 Knowledge Base & AI Guardrails
- **Katalog**: Mahsulotlar, narxlar, zaxira, rasmlar, ranglar va 12 oylik muddatli to'lov hisobi.
- **Biznes Qoidalari**: Yetkazib berish, Uzum Nasiya / Anorbank, 1 yillik rasmiy kafolat, qaytarish shartlari.
- **AI Guardrails**: Maksimal chegirma foizi (0-20%), narx to'qishni taqiqlash, norozi mijozni insonga yo'naltirish.

### 5. ⏰ Follow-up Automation (Drip Sequence)
- Narx so'rab javob bermagan mijozlarga 1-kunlik, 2-kunlik, 3-kunlik avtomatik eslatmalar ssenariysi.
- Anti-spam va tungi vaqt himoyasi.

### 6. 📲 Telegram Bot Integratsiyasi
- `@BotFather` API tokenini kiritib, bitta bosishda do'kon botini ulash.
- Hot Lead aniqlangan zahoti sotuvchi/rahbar Telegramiga zudlik bilan bildirishnoma jo'natish.

## 🛠 Texnologiyalar (Tech Stack)

- **Frontend**: React 18, Vite 8, Tailwind CSS v4, Lucide Icons, Modern Glassmorphism UI.
- **Backend / API**: Node.js, Express.js, Telegraf (Telegram Bot API), Web Speech API & HTML5 Audio.
- **AI & NLP Engine**: OpenAI GPT-4o / GPT-4o-mini, Google Gemini API, Universal Built-in NLP/RAG Engine.
- **Database**: Local JSON Database with automatic persistence.

## 🚀 Ishga Tushirish (Quick Start)

### 1. Repository'ni klonlash:
```bash
git clone https://github.com/AsilbekTurkmanov/Ai-sotuvchi.git
cd Ai-sotuvchi
```

### 2. Bog'liqliklarni o'rnatish:
```bash
npm install
```

### 3. Serverlarni ishga tushirish:
```bash
npm run dev
```

Brauzeringizda quyidagi manzillarni oching:
- **Dashboard & Chat**: [http://localhost:3000](http://localhost:3000)
- **Backend REST API**: [http://localhost:5000](http://localhost:5000)
